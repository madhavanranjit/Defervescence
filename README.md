# Defervescence — Smart Fever Tracker & Community Outbreak Detection

Defervescence is an open-source, AI-assisted mobile application that helps caregivers monitor and interpret fever in children. Beyond individual care, it aggregates anonymous geo-tagged fever data to detect climate-driven infectious disease outbreaks at community level — before hospital systems register a surge.

**Built with:** React · Vite · Capacitor · Supabase

**Status:** Usability trial ongoing (SUS + MAUQ). Play Store launch June 2026.

**Platform:** Android (iOS roadmap)

## Key Features

- Fever logging with trend visualisation
- AI-assisted severity guidance and warning sign detection
- PDF export for clinical consultations
- Offline-capable for low-connectivity settings
- Anonymous geospatial aggregation for outbreak detection *(in development)*
- District surveillance dashboard for health officers *(in development)*
